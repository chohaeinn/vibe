# 🎪 행사장 설계 AI - Streamlit

사용자가 입력한 행사 조건을 바탕으로 행사장 공간 구성과 운영 아이디어를 제안하는 Streamlit 앱입니다.

## 포함 기능
- 회원가입 / 로그인
- 행사 유형 선택
- 예상 인원수
- 진행 시간
- 예상 연령대
- 원하는 분위기
- 예상 입장료
- 실내 / 실외 선택
- 행사 규모 및 권장 공간 규모 제안
- 공간별 존 구성
- 추천 동선
- 분위기 연출
- 안전/혼잡 운영 포인트
- 입장료 기반 운영 전략

## 실행
pip install -r requirements.txt
streamlit run app.py
